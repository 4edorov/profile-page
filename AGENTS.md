## Agent skills

### Issue tracker

Issues live in GitHub Issues on `4edorov/profile-page`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one root `GLOSSARY.md` and ADRs in `docs/adr/`. See `docs/agents/domain.md`.
